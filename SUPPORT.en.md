## Asking Questions

- **GitHub Discussions** — best for "how do I…" and design questions.
- **GitHub Issues** — for reproducible bugs and concrete feature requests.
  Please use the issue templates.

## Reporting Problems

- Found a bug? Open an issue with the **Bug report** template.
- Found a security vulnerability? See [SECURITY.en.md](SECURITY.en.md) — **do not**
  file a public issue.
